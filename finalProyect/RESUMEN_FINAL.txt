  ARQUITECTURA DE TRADUCCIÓN DE DIRECCIONES
█████████████████████████████████████████████████████████████████████████████

FLUJO COMPLETO: Dirección Lógica → Dirección Física
────────────────────────────────────────────────────────────────────────────

  Proceso solicita:
  readMemory(logicalAddress: 0x00010502)
       │
       ├─→ OperatingSystem.readMemory()
       │    │
       │    └─→ MMU.readMemory()
       │         │
       │         ├─→ VERIFICAR TLB (Translation Lookaside Buffer)
       │         │    │
       │         │    ├─ Si HIT: retornar cached physicalAddress
       │         │    └─ Si MISS: continuar traducción
       │         │
       │         ├─→ EXTRAER COMPONENTES
       │         │    Using: ArchitectureConfig.getMasks()
       │         │    ├─ segmentId = (0x00010502 >> 16) & 0xFF = 0
       │         │    ├─ pageId    = (0x00010502 >> 8)  & 0xFF = 5
       │         │    └─ offset    = (0x00010502 >> 0)  & 0xFFFF = 2
       │         │
       │         ├─→ VALIDAR EN TABLA DE SEGMENTOS
       │         │    ├─ process.segmentTable.getSegment(0)
       │         │    ├─ Verificar permisos (read/write/execute)
       │         │    └─ Obtener: segment.pageTable
       │         │
       │         ├─→ VALIDAR EN TABLA DE PÁGINAS
       │         │    ├─ pageTable.getPage(5)
       │         │    ├─ Verificar if (page.isPresent())
       │         │    └─ Si no está en RAM: PageFault
       │         │
       │         ├─→ MAPEO PÁGINA → MARCO
       │         │    ├─ frameNumber = page.getFrameNumber()  → 42
       │         │    └─ Obtener: ram.getFrame(42)
       │         │
       │         ├─→ CALCULAR DIRECCIÓN FÍSICA
       │         │    └─ physicalAddress = (42 * 4096) + 2 = 172,034
       │         │
       │         ├─→ ALMACENAR EN TLB
       │         │    └─ tlb[0x00010502] = 172,034
       │         │
       │         └─→ ACCEDER A RAM
       │              ├─ ram.read(physicalAddress, size)
       │              ├─ Validar rango [0, 16777216]
       │              └─ Retornar: data[] desde memory[]

ESPACIOS DE DIRECCIÓN
─────────────────────────────────────────────────────────────────────────────
  Dirección Lógica:    32 bits  (0x00000000 - 0xFFFFFFFF)
  Dirección Física:    32 bits  (0x00000000 - 0xFFFFFFFF)
  Espacio direccionable: 4 GB

SEGMENTACIÓN
─────────────────────────────────────────────────────────────────────────────
  Bits para Segment ID:   8 bits
  Máximo de segmentos:    256 (2^8)
  Ejemplo de uso:
    • Segmento 0: CODE    (código ejecutable)
    • Segmento 1: DATA    (datos estáticos)
    • Segmento 2: STACK   (pila del proceso)
    • Segmento 3: HEAP    (memoria dinámica)
    • ... (hasta 252 segmentos más auxiliares)

PAGINACIÓN
─────────────────────────────────────────────────────────────────────────────
  Tamaño de página:       4096 bytes (4 KiB)
  Bits para offset:       12 bits (log₂(4096))
  Bits para Page ID:      8 bits
  Páginas por segmento:   256 (2^8)
  Máximo por proceso:     256 segmentos × 256 páginas = 65,536 páginas

MEMORIA FÍSICA
─────────────────────────────────────────────────────────────────────────────
  RAM Total:              16,777,216 bytes (16 MiB)
  Tamaño de Marco:        4096 bytes (igual a página)
  Total de Marcos:        4096 (16 MiB ÷ 4 KiB)
  Mapeo:                  1 página lógica ↔ 1 marco físico

MMU - MEMORY MANAGEMENT UNIT
─────────────────────────────────────────────────────────────────────────────
  TLB (Translation Lookaside Buffer):
    • Tamaño:             16 entradas (caché)
    • Propósito:          Acelerar traducciones frecuentes
    • Política:           FIFO (First In, First Out)

  Estadísticas:
    • TLB Hits:           Consultas encontradas en caché
    • TLB Misses:         Traducciones realizadas
    • Hit Rate:           Hits / (Hits + Misses)
